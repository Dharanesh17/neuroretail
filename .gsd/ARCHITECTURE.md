## Data Flow

1. **Transaction & Inventory Ingestion (7-Stage Pipeline):**
   - User uploads CSV/JSON via `DataUploadModule.jsx`.
   - `POST /api/datasets/upload` receives file bytes and creates an initial dataset record.
   - `POST /api/datasets/<id>/validate` verifies schema against required retail attributes.
   - `POST /api/datasets/<id>/clean` removes duplicates, fixes outliers, imputes missing values, and returns a data quality scorecard.
   - `POST /api/datasets/<id>/map-columns` performs fuzzy synonym matching to standard retail schema.
   - `POST /api/datasets/<id>/process` normalizes numerical values and encodes categorical features.
   - `POST /api/datasets/<id>/train` trains Gradient Boosting, Random Forest, and Ridge regressors, persisting model artifacts to `backend/models/`.
   - `POST /api/datasets/<id>/activate` sets the dataset as active, updating the executive dashboard.

2. **Dynamic Pricing & Demand Decision Loop:**
   - User requests product pricing recommendation or runs What-if simulation in `DynamicPricing.jsx` or `ScenarioSimulator`.
   - Backend evaluates inventory stock ratio, competitor prices, demand elasticity, and historical conversion.
   - Returns recommended retail price, price delta, expected profit margin, and auditable reasoning.
   - Actions taken are logged to the immutable Activity Trail (`AuditLog`).

## Technical Debt

- [ ] **Dual backend servers:** Both `backend/app.py` (Flask) and `backend/server.py` (`BaseHTTPRequestHandler`) exist with overlapping route logic. Consolidate exclusively onto `app.py`.
- [ ] **Automated Test Coverage:** `run_api_tests.py` provides integration testing, but unit tests with `pytest` (backend) and `vitest` (frontend) are missing.
- [ ] **Store Configuration:** Store profiles in `backend/data_store.py` are statically defined in Python dictionaries rather than dynamic DB tables.
- [ ] **Silent Fallback in API Client:** `frontend/src/api/client.js` falls back to mock data on network errors, which can obscure backend failure modes during live testing.
